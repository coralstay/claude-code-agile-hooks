## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
사용자가 직접 지적한 훅 시스템의 구조적 문제 5가지: 1) 턴어라운드 레이턴시(매 도구 호출마다 훅 프로세스 기동 비용), 2) 깨진 훅으로 인한 세션 마비(버그 있는 훅이 Edit/Write 같은 필수 액션을 영구히 막아버릴 위험), 3) 무한루프와 컨텍스트 왜곡(차단-재시도가 반복되며 컨텍스트가 오염되는 패턴), 4) 압축 시점의 데이터 유실(컨텍스트 압축 때 훅이 의존하는 세션 상태가 유실될 위험), 5) 병렬 처리 시 데이터 충돌(여러 서브에이전트/프로세스가 같은 작업 디렉토리를 동시에 건드릴 때의 레이스 컨디션 — 실제로 이번 세션에서 git-safety 훅 오탐, GitHub 재커밋으로 인한 로컬/원격 divergence 등으로 여러 번 겪었다). 사용자 지시: 다섯 문제를 전부 한 번에 풀려 하지 말고, 우선 "컨텍스트 플래그" 정도의 가벼운 장치로 1차 대응해야 한다 — 이게 우선순위가 높다.
<!-- SECTION:DESCRIPTION:END -->
