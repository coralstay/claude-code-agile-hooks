# 1.02 원칙

이 설계 문서의 모든 요구사항과 훅이 따라야 하는 불변 규칙이다. 원칙을 바꾸려면 3.05 설계 결정에 결정을 먼저 남기고, 최상위 원칙(최상위 1.02)에 어긋날 수 없다.

| ID | 원칙 | 근거 | 최상위 연결 |
| --- | --- | --- | --- |
| P-1 | **강제는 훅, 방법은 에이전트.** 기계적으로 검증할 수 있는 규칙은 반드시 훅으로 강제한다. 그 안에서 무엇을 어떻게 할지는 에이전트에게 남긴다. 훅은 필요한 만큼만 둔다. | CLAUDE.md의 약속은 프롬프트 인젝션 · 컨텍스트 압축으로 깨진다(1.01). 규칙을 기억하는 주체가 그 경로에 노출된 모델이므로 강제는 모델 밖 코드여야 한다. 반대로 규율을 끝까지 밀면 에이전트의 자발성이 사라진다 | 최상위 P6 |
| P-2 | **완전 독립형 훅.** 훅 파일은 다른 훅 파일을 반드시 import하지 않는다. 공용 모듈 · 라우터 · dispatcher를 두지 않는다. 훅 하나 = 스크립트 하나. | 공용 모듈 하나의 버그가 안전 훅 전체를 동시에 무력화하는 것을 막는다 — 특히 `config_guard.py` · `protect_secrets.py` · `block_dangerous_commands.py` 같은 보안 훅. 업스트림 두 곳(karanb192/claude-code-hooks, disler/claude-code-hooks-mastery)도 같은 구조다(decision-3) | 최상위 NFR-016 |
| P-3 | **사람 판단 지점은 두 곳으로 줄인다.** 백로그 승인(draft → 승격)과 push · 원격 병합 전 리뷰는 반드시 사람이 한다. 훅은 이 두 지점을 대신 판단하지 않고, 그 앞에서 멈추게만 한다. 로컬 병합(rebase 후 fast-forward)까지는 자동화한다. | 백로그 내용과 코드의 옳음은 사람이 봐야 판단할 수 있다. 판단 지점을 늘리면 사람이 병목이 되고, 줄이되 없애지 않아야 검증 안 된 코드가 원격에 오르지 않는다(decision-4, decision-11) | 최상위 RAIL-009 |
| P-4 | **문자열 매칭의 한계를 인정한다.** 명령 문자열 매칭 훅은 실행 파일 경로를 basename으로 정규화하고 명령 위치로 판정하는 데까지만 한다. syscall 레벨 강제는 이 컴포넌트의 범위 밖이다. 훅만으로 완결된 방어선이라고 반드시 주장하지 않는다. | Claude Code 훅은 도구 호출의 문자열만 받는다. 정규식 · 토큰 매칭은 인코딩 트릭 · alias · 간접 실행으로 우회된다. 확실한 방어는 커널 레벨 강제(seccomp · eBPF · Landlock)이고, 그것은 Claude Code 프로세스를 감싸는 별도 레이어가 할 일이다. 실제 방어선은 이 훅과 Claude Code의 `permissions.deny` · 샌드박스의 조합이다(decision-1) | — |
| P-5 | **복붙 함수 drift는 REGISTRY로 잡는다.** P-2 때문에 여러 훅에 손으로 복사한 함수는 `dedup_drift_guard.py`의 REGISTRY에 등록하고, 사본이 어긋나면 커밋을 막는다. 하나의 소스에서 생성하는 codegen 전환은 보류한다(`TBD(Q-5)`). | 한 사본만 고치고 나머지를 방치한 버그가 실제로 있었다(`is_backlog_project()`). 독립성을 지키면서 drift를 막는 가장 작은 수단이 사후 검증이다(decision-2) | 최상위 NFR-016 |

## 원칙 사이의 관계

- P-2와 P-5는 한 쌍이다. 독립성(P-2)의 대가가 코드 중복이고, 그 대가가 버그로 번지는 것을 P-5가 막는다.
- P-1과 P-4는 한 쌍이다. P-1은 "강제할 수 있는 것은 강제한다"이고, P-4는 "문자열로 강제할 수 있는 것은 거기까지다"이다. 막히지 않는 우회 경로는 4.03 미결 사항에 남기고, 에이전트에게는 가드에 막히면 우회하지 말고 사람에게 보고하라고 요구한다.
- P-3은 P-1의 경계다. 기계적으로 검증할 수 없는 판단을 훅이 흉내 내지 않는다. 예: `pre_push_check.py`는 태스크가 Done이고 final summary가 있는지만 보고, 사람이 코드를 실제로 봤는지는 판정하지 않는다.
