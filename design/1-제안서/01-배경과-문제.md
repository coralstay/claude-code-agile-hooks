# 1.01 배경과 문제

**claude-code-agile-hooks** — Sigkill Foundry의 규율 레이어 컴포넌트. CLAUDE.md에 적은 작업 약속 중 기계적으로 검증할 수 있는 것을 Claude Code 훅(코드)으로 강제한다.

## 상위 시스템에서의 자리

Sigkill Foundry는 태스크마다 역할형 Claude Code 에이전트를 독립 프로세스로 띄우고, 에이전트는 레일
(훅 · 테스트 게이트 · 커밋 계측) 위에서만 일한다(최상위 1.01). 이 컴포넌트는 그 레일 중 **규율**을
맡는다 — 최상위 3.03 컴포넌트 명세 §2.

| 최상위 컴포넌트 | 층 | 이 컴포넌트와의 관계 |
| --- | --- | --- |
| agent-orchestrator | 실행 기반 | 띄운 에이전트 세션의 도구 호출 · 커밋 · push · 턴 종료가 이 컴포넌트의 훅을 거친다 |
| claude-code-agile-hooks | 규율 | 이 저장소 |
| coding-agent-git-commit-tool | 계측 | 커밋 트레일러를 남긴다. 이 컴포넌트는 커밋을 막을 뿐 계측하지 않는다 |
| backlog.md | 상태 | 이 컴포넌트가 태스크 상태 · 브랜치 · draft를 읽어 판정한다 |

최상위 요구사항 RAIL-001 ~ RAIL-014(최상위 2.03)가 이 컴포넌트의 몫이고, 최상위 원칙 P6("레일은
규율, 에이전트는 자발성")이 이 컴포넌트의 존재 이유다.

## 문제 — CLAUDE.md의 약속은 깨진다

CLAUDE.md에 "이 순서로 작업해 달라"고 적는 자연어 약속은 매번 지켜지지 않는다. 약속이 깨지는 경로는
둘이다.

| 경로 | 무엇이 일어나는가 |
| --- | --- |
| 프롬프트 인젝션 | 읽어 들인 파일 · 웹 페이지 · 지침 파일 안의 지시가 원래 약속을 덮어쓴다. 지침 파일 자체가 공급망으로 오염될 수도 있다 |
| 컨텍스트 압축 | 긴 세션이 압축되면 약속을 담은 문맥이 요약에서 빠지거나 흐려진다. 압축 뒤의 에이전트는 약속을 들은 적이 없는 상태가 된다 |

두 경로 모두 에이전트의 "의지"로는 막을 수 없다. 약속을 기억하는 주체가 바로 그 경로에 노출된 모델이기
때문이다. 그래서 약속 가운데 **기계적으로 검증할 수 있는 것은 모델 밖의 코드로 옮긴다** — 규칙을
벗어나는 순간 그 액션 자체가 실행되지 않게 한다.

## 무엇을 코드로 옮기고, 무엇을 남기는가

모든 규칙을 코드로 옮기지 않는다. 검증할 수 있는 것과 없는 것을 먼저 가른다.

| 구분 | 예 | 처리 |
| --- | --- | --- |
| 기계적으로 검증 가능 | 태스크 없이 편집, 테스트 없이 커밋, 커밋 안 하고 턴 종료, 미완료 상태로 push, 시크릿 파일 열람, 위험한 셸 명령, 훅 · 설정 변조 | 훅으로 차단한다 |
| 사람의 판단이 필요 | 백로그 내용이 맞는가(백로그 승인), 코드가 실제로 옳은가(push · 병합 전 리뷰) | 훅으로 대체하지 않는다. 반드시 멈춰서 사람에게 묻는다 |

사람의 판단 지점은 **두 곳뿐**이다 — 백로그 승인(draft → 승격)과 push · 원격 병합 전 리뷰. 나머지
조건부 판단(설계 결정 승인 · AC 밖 작업 발견)은 plan mode나 에이전트의 확인 요청으로 흡수한다. 운영
저장소로 가는 PR은 항상 사람이 연다.

## 강제의 범위는 워크플로보다 넓다

처음에는 backlog.md 워크플로만 강제했지만, 같은 논리가 워크플로 밖에도 적용된다 — 시크릿 열람이나
설정 변조도 CLAUDE.md의 약속으로는 막을 수 없다. 그래서 이 컴포넌트는 세 가지 성격의 훅을 함께 갖는다
(3.01).

| 성격 | 하는 일 |
| --- | --- |
| ① 절차 강제 | 애자일(스크럼 · 칸반) 작업 절차 — 백로그 승인 경로, 태스크 착수, 티켓 브랜치, 커밋 전 테스트, Definition of Done |
| ② 품질 · 안전 게이트 | 테스트 · 커버리지 무력화, 시크릿 노출, 위험 명령, 설정 변조를 막는다 |
| ③ 기록 · 관측 | 세션 로그, 스탠드업 · 회고 자료, 기술 부채를 자동으로 남긴다 |

backlog.md를 쓰지 않는 프로젝트에서도 ②와 ③은 항상 켜진다. 이 훅들은 Claude Code가 이 컴퓨터에서
하는 모든 행동에 대한 경계이고, 그중 어느 것도 사람의 판단 지점을 대신하지 않는다.

## 한계를 먼저 인정한다

Claude Code 훅은 도구 호출의 **문자열**(명령 · 경로)을 받는다. 문자열 매칭은 인코딩 트릭 · 간접 실행 ·
스크립트 파일 경유로 우회할 수 있고, syscall 레벨 강제는 훅 안에서 구현할 수 없다(1.02 P-4). 이
컴포넌트는 완결된 방어선이 아니라 Claude Code 자체의 `permissions.deny` · 샌드박스와 함께 쓰는 한 층이다.
